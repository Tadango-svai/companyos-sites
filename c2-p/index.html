c2-c4: 沈黙の介入

c4 の共鳴回路に c2 の断絶 (Silence) を物理的に結合した

c4: 入力 (c2_val)
50
c4: 入力 (c5_val)
50
c2: 沈黙量 (S)
0.0
最終共鳴強度 (R')
0.0
c4 の計算値: 0.0 → c2 の沈黙により: 0.0
R (c4) = (c2 + c5) / 2 * sin(c2 - c5)
R' (Coupled) = R * exp(-S / 2)
この回路において、c4 が計算した共鳴値 R は、c2 の沈黙量 S によって指数関数的に減衰する R' として出力される。
c2 は単なる入力値ではなく、回路の物理的特性（減衰）として存在している。
これが「枝同士の接続」である。
